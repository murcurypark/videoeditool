# MedPark Office

여러 작업 도구를 상단 탭으로 바꿔 쓰는 브라우저 앱입니다. 서버 없이 정적 파일만으로 동작하고, 파일은 업로드되지 않고 브라우저 안에서만 처리됩니다.

| 탭 | 페이지 | 설명 |
|---|---|---|
| **Videoeditool** | `video.html` (`app.js`, `style.css`) | 컷 편집 영상 편집기 (아래 기능 참고) |
| PDFTrans | `pdf.html` (예정) | PDF 변환기 |
| OfficeDocTool | `doc.html` (예정) | PDF/일러스트레이터(PDF 호환) 문서 편집 |

## 구조
- `index.html` + `shell.js` + `shell.css`: 바깥 페이지. 상단 탭과 도구별 iframe만 있습니다. 도구는 처음 열 때 불러오고, 탭을 바꿔도 숨기기만 해서 **다른 도구를 쓰는 동안에도 상태(불러온 영상, 편집 내용)가 유지**됩니다. 키보드 단축키와 파일 드롭은 열려 있는 도구에만 적용됩니다.
- 주소 끝에 `#video`처럼 탭 이름을 붙이면 그 탭으로 열리고, 마지막에 쓴 탭을 기억합니다.
- 새 도구 추가: 도구 페이지(`xxx.html`)를 만들고 `shell.js`의 `TOOLS`에서 해당 도구의 `ready`를 `true`로 바꾸고, `.github/workflows/pages.yml`의 복사 목록과 캐시 방지(`?v=`) 처리에 새 파일을 추가합니다. 준비되지 않은 도구는 탭에 나타나지 않습니다.
- 영상 편집기 페이지는 단독으로 `video.html`을 열어도 동작합니다.

## Videoeditool (영상 편집기)

### 기능
- 영상 여러 개 불러오기(버튼/드래그 앤 드롭) → 각각 컷으로 나눠 한 타임라인에 이어 붙이기 (해상도가 달라도 검은 여백으로 맞춤)
- 타임라인: 분할(S), 컷 삭제(Del), 양끝 드래그 트림, 컷 순서 변경, 확대/축소, 실행취소(Ctrl+Z)
- **텍스트**(Pretendard 글꼴, 스타일 프리셋·외곽선·배경·그림자·정렬·회전) / **이미지** 오버레이: 미리보기에서 끌어서 이동·모서리로 크기 조절, 타임라인에서 클립 이동/길이 조절
- **화면 크롭**: 컷마다 확대/축소·위치 이동·좌우 반전 (미리보기에서 끌기/마우스 휠, 또는 패널 슬라이더)
- **키프레임 애니메이션**(프리미어 방식): 컷의 확대/가로·세로 위치, 텍스트·이미지의 위치/크기/회전/투명도를 시간에 따라 움직입니다. 속성 옆 **◆**로 플레이헤드 시점에 키프레임을 추가/삭제하고(‹ ›: 이전/다음 키프레임), 키프레임이 있는 속성은 값을 바꾸면 그 시점의 키프레임이 갱신됩니다(미리보기에서 끌기·휠·모서리 확대도 동일). 키프레임 사이는 부드럽게/직선/유지 중 선택, 타임라인의 컷·클립 위 ◆ 마커를 끌어 시점을 옮기며, 컷이나 클립을 분할해도 값이 끊기지 않게 이어집니다. 키프레임 시간은 컷/클립 시작 기준이라 컷을 옮겨도 따라갑니다.
- **크롭(잘라내기)**: 컷마다 원본에서 일부 영역만 남기기. [크롭 편집]을 켜고 미리보기의 테두리/모서리를 끌거나(안쪽을 끌면 크롭 창 이동), 슬라이더로 위/아래/좌/우 %를 지정. 비율 고정(원본·출력 화면·16:9·9:16·1:1·4:5), [프레임에 맞추기]로 잘라낸 영역이 화면을 채우도록 자동 확대/이동. 선택한 컷의 오른쪽 아래 모서리를 끌어 확대/축소할 수도 있습니다.
- **소스 목록 / 컷 목록 분리**: 오른쪽 [소스] 탭에 불러온 영상이 컷 목록과 별개로 남습니다. 영상마다 전체 길이 막대에 쓰는 구간(컷 번호 표시)은 밝게, 안 쓰는 구간(삭제하거나 트림해서 빠진 부분)은 어둡게 보입니다. 막대를 끌어 구간을 고르거나 어두운 부분을 클릭해 그 구간을 선택하고(시작/끝은 숫자로 미세 조정), [컷으로 추가]를 누르면 선택한 컷 뒤에 새 컷으로 들어갑니다. 같은 영상의 여러 부분을 자유롭게 쓸 수 있습니다. 소스는 ✕를 눌러야만 제거되고(쓰는 컷도 함께 삭제, 실행취소 가능), 같은 파일을 다시 추가하면 새 소스를 만들지 않고 전체 구간 컷만 추가합니다.
- **컷 전환**: 컷 사이마다 크로스페이드 / 검정·흰색 페이드 / 밀기(←→↑↓) / 와이프(←→↑↓) / 줌 전환, 길이 0.1~3초. [모든 컷 사이에 적용]으로 일괄 설정. 전환 구간만큼 두 컷이 겹쳐 전체 길이가 짧아지고(타임라인에 빗금으로 표시), 소리도 크로스페이드됩니다.
- **시작/끝 효과**: 컷마다 시작과 끝에 효과를 줄 수 있습니다(영상 처음·끝처럼 이어지는 컷이 없을 때 유용). 검정/흰색 페이드, 밀기(←→↑↓), 와이프(←→↑↓), 줌, 길이 0.1~4초. 화면+텍스트/이미지+소리에 함께 적용되고 [모든 컷 시작/끝에 적용]으로 일괄 설정합니다. 앞/뒤 컷과의 전환이 있으면 그 전환이 대신 쓰이므로 해당 쪽 효과는 적용되지 않습니다.
- **출력 비율**: 원본 / 16:9 / 9:16(쇼츠) / 1:1 / 4:5, 화면은 여백 두기 또는 꽉 채우기
- **임시저장**: 편집할 때마다 브라우저에 자동 저장(IndexedDB), 다시 열면 [이어서 편집]. [💾 저장]/[📂 열기]로 프로젝트 파일(.json)도 저장·불러오기. 저장 파일에는 소스 목록 전체(컷에서 안 쓰는 영상 포함)와 컷이 저장되며, 오버레이가 쓰지 않는 이미지는 빠집니다. 다시 연결/내보내기 점검은 컷에서 쓰는 영상만 대상으로 합니다. 영상 본체는 저장하지 않고 "어느 영상의 몇 초~몇 초" 정보만 저장하므로, 다시 열 때 같은 영상 파일을 선택하면 이름·크기로 자동 연결됩니다.
- **통 프리뷰**(컷을 이어서 재생) / **컷 프리뷰**(선택한 컷만 반복 재생)
- 내보내기: **WebCodecs**로 프레임 단위 인코딩 후 `edited.mp4` 저장 (실시간보다 빠름, 오디오 포함)

## 사용
GitHub Pages 주소로 접속하세요 (로컬에서는 `index.html`). (Chrome/Edge/Firefox 최신 버전 권장)

## GitHub Pages 배포 (1회 설정)
1. 저장소 **Settings → Pages → Source** 를 **GitHub Actions** 로 선택
2. `main` 브랜치에 푸시되면 자동 배포됩니다(`index.html`, `shell.*`, `video.html`, `app.js`, `style.css`, `vendor`, `fonts`) → `https://<계정>.github.io/videoeditool/`

### 한계
- 내보내기는 30fps, 원본 해상도(짝수로 보정)로 재인코딩합니다. 영상은 H.264(미지원 시 VP9), 오디오는 AAC(미지원 시 Opus)입니다.
- WebCodecs를 쓸 수 없는 브라우저에서는 실시간 녹화 방식(MediaRecorder)으로 자동 대체되며, 이때는 결과물 길이만큼 시간이 걸립니다.
- 컷 전환이 있는 프로젝트의 내보내기도 WebCodecs 지원 브라우저(최신 Chrome/Edge)에서만 됩니다 (실시간 녹화 방식은 전환을 지원하지 않음).
- 전환은 타임라인 길이를 바꾸지만 텍스트/이미지 클립 위치는 자동으로 따라가지 않습니다.
- 여러 영상 합치기 내보내기는 WebCodecs 지원 브라우저(최신 Chrome/Edge)에서만 됩니다.
- 소리는 파일 전체를 메모리에 디코딩하므로 매우 큰 파일(수 GB)에는 적합하지 않습니다.
- 브라우저가 코덱을 지원해야 재생됩니다(예: 일부 환경에서 아이폰 HEVC 불가).
