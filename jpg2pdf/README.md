# jpg2pdf — 긴 이미지를 페이지로 자동 분할해 PDF로

웹툰·긴 캡처처럼 세로로 긴 이미지를 A4 등 고정 크기 페이지로 잘라 PDF 한 파일로 만듭니다.

- 가로폭을 페이지 본문 폭에 맞추고, 페이지 높이만큼 세로로 자릅니다.
- 자르는 위치 근처에서 **빈 가로줄(단색 행)** 을 찾아 글자·컷이 중간에 잘리지 않게 합니다. (`--no-smart`로 끌 수 있음)
- 이미지를 여러 장(또는 폴더) 주면 숫자 순(자연 정렬)으로 이어 붙여 하나의 긴 이미지처럼 처리합니다.

## 설치
```
pip install Pillow
```

## 사용
```
python jpg2pdf.py long.jpg                       # → long.pdf (A4, 여백 10mm, 150dpi)
python jpg2pdf.py ep1_01.jpg ep1_02.jpg -o ep1.pdf
python jpg2pdf.py ./images/ --page A5 --margin 5 --dpi 200
```

| 옵션 | 기본 | 설명 |
|---|---|---|
| `-o` | 첫 입력명.pdf | 출력 파일 |
| `--page` | A4 | A4/A5/B5/Letter 또는 `200x300`(mm) |
| `--margin` | 10 | 여백(mm) |
| `--dpi` | 150 | 해상도 |
| `--no-smart` | | 빈 줄 찾기 없이 고정 높이로 자르기 |
| `--search` | 0.2 | 빈 줄 탐색 범위(페이지 높이 비율) |
| `--tolerance` | 8 | 빈 줄 판정 허용 명암 차(0~255). 배경이 지저분하면 올리세요 |
| `--quality` | 90 | JPEG 품질 |

## 한계
- 배경이 사진/그라데이션인 이미지는 빈 줄을 못 찾아 고정 높이로 자릅니다 (`--tolerance` 조절).
- 모든 이미지를 메모리에 올려 처리하므로 매우 큰 입력에는 메모리가 많이 듭니다.
